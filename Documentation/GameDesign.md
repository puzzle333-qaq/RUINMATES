# 《废墟合伙人》(Ruinmates) 游戏设计方案 (Game Design Document)

---

## 1. 游戏愿景与定位

- **游戏名称**：《废墟合伙人》 (Ruinmates)
- **核心定位**：1–4 人联机合作、PvE 战术撤离探索 RPG (Extraction RPG)。
- **引擎平台**：Unreal Engine 5.8 (PC / Windows)。
- **核心体验叙事**：在文明崩塌后的废墟都市与工业遗迹中，玩家组成 1–4 人的佣兵合伙人小队，受雇深入高危辐射封锁区搜刮遗留物资、武器图纸与核心能源。撤离点受限且局势瞬息万变，玩家必须在全灭失物与安全撤离之间做出权衡。

---

## 2. 核心玩法循环 (Core Gameplay Loop)

```
       ┌────────────────────────────────────────────────────────┐
       │                 安全基地营地 (The Shelter)              │
       │   - 武器仓库与战利品结算                               │
       │   - 组队大厅 (1-4人) 与准备出击                        │
       └───────────────────────────┬────────────────────────────┘
                                   │ 确认出击 (Listen Server Travel)
                                   ▼
       ┌────────────────────────────────────────────────────────┐
       │                高危废墟封锁区 (The Ruins)               │
       │   - 战术移动、体力与耐力管控                           │
       │   - 废墟建筑探索与物资搜刮 (IInteractable)              │
       │   - 与巡逻变异体 / 机械防御系统的战术枪战               │
       └───────────────────────────┬────────────────────────────┘
                                   │ 激活撤离点并坚持倒计时
                                   ▼
       ┌────────────────────────────────────────────────────────┐
       │                  撤离与数据结算 (Extraction)           │
       │   - 成功撤离：所有带出物资存入本地/云端存档             │
       │   - 任务失败：损失当局带入及搜刮的非受保护物品         │
       └───────────────────────────┬────────────────────────────┘
                                   │ 携物资返回基地
                                   └───────────────┘
```

## 3. 核心机制详解

### 3.1 移动与体态系统 (Locomotion & Vitals)
- **体态档位**：
  - **站立奔跑 (Sprint)**：消耗耐力（Stamina）。耐力归零后强制降回常速，需静止或慢走恢复。
  - **常速慢跑 (Jog / Walk)**：标准巡逻探索状态，耐力缓慢回复。
  - **蹲伏潜行 (Crouch)**：大幅降低移动噪音与受击轮廓，增强射击稳定性，降低武器散布。
  - **举镜瞄准 (Aim Down Sights / ADS)**：按住瞄准键进入精确瞄准模式，视野缩放、视角灵敏度降低、后坐力恢复速率提升。
- **生命与倒地机制**：
  - 生命值降至 0 时进入死亡/倒地状态（`DeathState`），触发复制通知。

### 3.2 武器与战术枪战系统 (Gunplay & Ballistics)
- **武器分类 (GameplayTags)**：
  - `Weapon.type.rifle`：突击步枪，泛用全距离压制。
  - `Weapon.type.pistol`：手枪/便携随身武器。
  - `Weapon.type.sniper`：高精度狙击步枪。
  - `Weapon.type.shotgun`：近距离面杀伤霰弹枪。
  - `Weapon.type.lmg`：重机枪，重火力持续压制。
  - `Weapon.type.melee`：近战应急冷兵器。
- **射击与弹道运算**：
  - **射击模式**：半自动（Semi）、全自动（FullAuto）、点射（Burst）。
  - **服务器权威射线 (Server Hitscan)**：客户端仅发送开火意图（`Server_TryFire`），服务器统一打出射线、执行材质穿透与伤害结算，避免客户端网络篡改命中。
  - **后坐力与散布机制**：
    - 腰射散布（`HipFireSpread`）与举镜瞄准散布（`AimingSpread`）。
    - 垂直跳动与水平漂移，射击后坐力曲线自动回复。
  - **战术换弹与空仓换弹**：
    - 战术换弹（Tactical Reload）：弹匣尚有余弹，保留膛内 1 发子弹，换弹动作更迅捷。
    - 空仓换弹（Empty Reload）：弹匣打空，必须执行额外的拉栓/推机柄动作。

### 3.3 背包与装备管理 (Inventory & Loadout)
- **多栏位武器管理**：
  - 角色默认挂载 `UWeaponInventoryComponent`，在生成时自动从 `DefaultWeaponClass` 实例化开局武器并就手装备。
  - 支持快捷切枪（`CycleNextWeapon` / `EquipWeaponAtIndex`）。
  - 双插槽挂载：当前激活武器挂载于角色右手掌心插槽（`WeaponSocket_R`），备用武器自动收放于后背/侧腰挂点（`WeaponHolster_R`）。

### 3.4 1–4 人联机与跨图旅行 (Session & Party System)
- **Listen-Server 架构**：房主作为服务器主持会话，其他 1–3 名合伙人以客户端加入。
- **漫游旅行存档保护 (SaveTravel)**：
  - 在房主切换关卡（从安全基地切到废墟关卡，或从废墟撤离切回基地）前，`URuinmatesSessionManager` 自动将全队各队员的角色数据、背包数据快照打包写入专用序列化存档（`FRuinmatesMemberSave`）。
  - 切图加载完毕、客户端重新 `OnPostLogin` 登录时，自动从保存的快照重构队员背包与武器数据，确保战利品跨关卡不丢失。

## 4. 阶段性里程碑规划

1. **里程碑 1 (M1) - 单人射击与动作冒烟**：
   - 步枪单人射击、后坐力表现、换弹、耐力奔跑与瞄准姿态平滑衔接。
2. **里程碑 2 (M2) - 双人联机与视线一致性**：
   - 双人局域网联机，3P 动作（奔跑、蹲伏、射击火光、换弹姿势、左手 IK 贴合）双向同步。
3. **里程碑 3 (M3) - 组队撤离与战利品保留**：
   - 房主带队进入废墟关卡，搜刮战利品道具，完成撤离交互，切回主城后战利品背包无损继承。
